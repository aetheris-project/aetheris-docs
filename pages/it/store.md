# Store integrazioni

Moduli pronti all'uso per la piattaforma Aetheris, gratuiti.

Ogni voce dello store è una pull request accettata nel repository [aetheris-addons](https://github.com/aetheris-project/aetheris-addons).

## Come installare

1. Scegli il modulo dallo store.
2. Clona il modulo nella cartella `addons/` del tuo deployment.
3. Riavvia il backend.

## Moduli disponibili

| Modulo | Descrizione |
| --- | --- |
| Stripe Gateway | Pagamenti carta e SEPA |
| PayPal Gateway | Pagamenti PayPal |
| Mollie Gateway | Pagamenti europei multipli |
| Email SMTP | Invio email transazionali |
| Discord Notifier | Notifiche su canale Discord |
| Telegram Notifier | Notifiche su Telegram |

Vedi anche: [Moduli](addons.md), [Whitelabeling](whitelabel.md).
