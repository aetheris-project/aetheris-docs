# Glossario

Riferimento rapido per i termini usati nella piattaforma Aetheris.

| Termine | Definizione |
| --- | --- |
| **Aetheris** | Piattaforma di facturazione e virtualizzazione |
| **Control panel** | Pannello di controllo web (admin + client) |
| **Node** | Macchina hypervisor che ospita server |
| **Server** | Istanza (VM, container, game server) creata per un client |
| **Plan** | Offerta con risorse e prezzo |
| **Invoice** | Fattura con righe, IVA e scadenza |
| **Dunning** | Processo di recupero pagamenti scaduti |
| **Egg** | Template Pterodactyl per un gioco specifico |
| **Whitelabel** | Branding personalizzato a runtime |
| **Accent** | Colore primario del tema (emerald/indigo/amber) |
| **Token** | JWT per autenticazione API |
| **BullMQ** | Sistema di code per job background |
| **Provisioning** | Creazione automatica di un server |
| **Telemetry** | Dati utilizzo in real-time (CPU, RAM, disco) |
| **VNC** | Console terminale remota via WebSocket |

Vedi anche: [Architettura](architecture.md).
